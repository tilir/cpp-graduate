# LRU на C

Сборка и запуск (компилятор C11 и make):

```sh
make
echo '2 6 1 2 1 2 1 2' | ./lru
# 4
make test
```

На stdin подаются неотрицательная вместимость кеша, количество запросов
и указанное количество целых чисел. Числа — знаковые 64-битные,
разделитель — любой пробельный символ. На stdout выводится только число
попаданий и перевод строки. Ошибки ввода и выделения памяти выводятся
в stderr с ненулевым кодом завершения. Данные после указанного количества
запросов не обрабатываются. При нулевой вместимости все запросы — промахи.

## Компоненты

- `include/list.h`, `src/list.c`: двусвязный циклический список с сигнальным
  узлом. Звено встраивается в произвольную структуру; список не выделяет
  память и не владеет данными. Вставка и удаление — O(1).
- `include/int_map.h`, `src/int_map.c`: таблица `int64_t → void *` с цепочками
  коллизий. Владеет только массивом корзин; записи принадлежат вызывающему коду.
  Число корзин задаётся при создании. Поиск и вставка — в среднем O(1)
  при ограниченном коэффициенте заполнения; удаление известной записи — O(1).
- `include/lru.h`, `src/lru.c`: кеш с непрозрачным типом и операциями
  `lru_create`, `lru_access`, `lru_destroy`. Объединяет компоненты и владеет
  пулом записей. Начало списка — последний использованный элемент, конец —
  кандидат на вытеснение. Попадание переносит запись в начало; промах
  переиспользует самую старую запись, если кеш заполнен.
- `src/main.c`: потоковый ввод, проверка диапазонов и подсчёт попаданий.

Память выделяется при создании кеша, в обработке запросов выделений нет.
Программа использует O(min(вместимость, число запросов)) памяти и в среднем
O(число запросов) времени. Худший случай при коллизиях — O(вместимость)
на запрос; хеширование не обеспечивает защиты от специально подобранного
ввода. Компоненты не зависят от stdin/stdout и не требуют глобального состояния.
Контракты владения и допустимых операций описаны в заголовках.

Тесты требуют Python 3 (стандартная библиотека). Проверяются компоненты,
принудительные коллизии, вытеснение, обновление давности, крайние значения,
неверный ввод, длинные последовательности и 300 случайных сравнений
с простой эталонной реализацией.
