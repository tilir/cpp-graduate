# LRU на C

Сборка и запуск:

```sh
make
printf '2 6 1 2 1 2 1 2\n' | ./lru
# 4
```

Нужны C-компилятор и Make. Для тестов дополнительно нужен Python 3,
сторонние пакеты не требуются.

```sh
make test  # Собрать программу и запустить тесты
make clean # Удалить исполняемый файл
```

Тесты проверяют пример, вытеснение и обновление давности при попадании,
нулевую ёмкость, пустой входной набор, отрицательные числа, границы int64,
ошибочный ввод и длинные последовательности. Ещё 300 воспроизводимых
случайных наборов сравниваются с простой моделью LRU на списке.
Компилятор и флаги можно задать через `make CC=clang CFLAGS='-std=c11 -O0 -g'`.
При смене флагов сначала выполните `make clean`.

На stdin: неотрицательный размер кеша, неотрицательное количество элементов,
затем указанное количество целых чисел (знаковые 64-битные значения).
Пробелы и переводы строк взаимозаменяемы.
На stdout: количество попаданий и перевод строки.

Кеш изначально пуст. Попадание обновляет давность использования элемента.
При промахе элемент добавляется в кеш; если кеш заполнен, вытесняется элемент,
который дольше всего не использовался. При нулевой ёмкости попаданий нет.

Реализация использует хеш-таблицу с цепочками и двусвязный список.
Среднее время обработки — O(n), память — O(min(k, n)), где k — ёмкость,
n — количество элементов. Коллизии могут ухудшать время поиска.
Вход обрабатывается последовательно, без хранения всей последовательности.
