# LRU на C++

Нужны компилятор C++17 и CMake 3.16 или новее.

```sh
cmake -S . -B build
cmake --build build
echo '2 6 1 2 1 2 1 2' | ./build/lru
# 4
ctest --test-dir build --output-on-failure
```

На вход подаются неотрицательные вместимость кеша и число запросов,
затем целочисленные ключи. Числа должны помещаться в тип `long long`,
а вместимость — также в `std::size_t`. Программа выводит число попаданий. Ошибки ввода выводятся в stderr
с ненулевым кодом завершения; лишние данные после запросов игнорируются.

`cache.hpp` содержит шаблон `caches::cache_t<T, KeyT = int>`:
`T` — тип страницы, `KeyT` — тип ключа. `std::list<std::pair<KeyT, T>>`
хранит страницы от самой недавно использованной к самой старой,
а `std::unordered_map` сопоставляет ключам итераторы списка.
Поиск и обновление занимают в среднем O(1), память — O(число записей).
Ключ должен поддерживать `std::hash`, сравнение на равенство и копирование.

```cpp
caches::cache_t<std::string> cache{2};
auto load = [](int key) { return std::to_string(key); };
bool hit = cache.lookup_update(10, load);
```

Загрузчик передаётся при каждом запросе и вызывается только при промахе:
когда в индексе нет запрошенного ключа, независимо от наличия других записей.
Ключ и страница — разные сущности: загрузчик получает `KeyT` и возвращает `T`.
В драйвере это `PageId` и `Page`; только учебный загрузчик возвращает сам ключ.
При попадании `splice` переносит существующий узел в начало без копирования
страницы. При промахе сохраняется результат загрузчика и при необходимости
вытесняется последняя запись. При нулевой вместимости каждый запрос — промах,
загрузчик не вызывается. Загрузчик не должен повторно
обращаться к тому же кешу.

Инкапсуляции пока нет: это `struct` с открытыми полями `sz_`, `cache_`
и `hash_`. Их можно изучать напрямую; при изменении нужно самостоятельно
сохранять согласованность списка и индекса. В примере кеш создаётся и используется на месте; управление копированием
и обработка исключений оставлены для следующих лекций.

CTest проверяет шаблон с разными типами, давность, вытеснение, загрузчики
и нулевую вместимость. Если найден Python 3, также запускаются проверки
ввода и 300 случайных сравнений с эталоном (перенесены из C-версии).
